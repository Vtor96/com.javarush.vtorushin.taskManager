# Task Manager

Полноценное Spring-приложение с богатым набором функционала: REST API, безопасность, работа с базой данных, логирование, мониторинг, а также настройка CI/CD для деплоя.

## Технологии

- **Java 21** + **Spring Boot 3.5.11**
- **Spring Data JPA** + **Hibernate 6.6** - работа с БД
- **PostgreSQL** - основная БД, **H2** - для тестов
- **Liquibase** - миграции схемы
- **Spring Security** + **jjwt (0.12.3)** - аутентификация по JWT
- **Spring Boot Actuator** + **Micrometer** + **Prometheus** - метрики
- **Grafana** - визуализация
- **Lombok** - boilerplate
- **Maven** - сборка
- **JUnit 5** + **Mockito** + **MockMvc** - тесты

## Возможности

- Регистрация и аутентификация пользователей (JWT);
- CRUD для задач: создание, чтение, обновление, удаление;
- Изоляция задач по пользователям — чужие задачи недоступны;
- Фильтрация задач по статусу;
- Валидация входных данных (`@Valid`, Bean Validation);
- Логирование запросов и действий пользователей.
